# website.state

**Pradeep Sales — Order Management System**

A real-time order tracking dashboard for Pradeep Sales (Prayagraj, UP). Tracks orders through Received → Processing → Billing → Dispatched with SLA monitoring, Kanban board, and a retailer-facing portal.

## Features

- 📊 **Dashboard** — KPI cards, recent orders, SLA alerts
- ⊞ **Live Board** — Kanban pipeline (Received → Processing → Billing → Dispatched)
- 📋 **All Orders** — Searchable, filterable order table with PDF/CSV export
- 🔗 **Retailer Portal** — Public order tracking by Order ID
- ⏱ **SLA Tracking** — Priority-based SLA (Normal: 2h, Urgent: 30m, Critical: 15m)
- 🔒 **Passkey Login** — Simple team-only access gate

## Tech Stack

- HTML / CSS / JavaScript (vanilla, no framework)
- Instrument Sans + Instrument Serif (Google Fonts)

## Getting Started

1. Clone the repo
2. Open `index.html` in a browser — or deploy to Vercel

## Deployment

Push to GitHub → Connect to [Vercel](https://vercel.com) → Auto-deploys on every push.
